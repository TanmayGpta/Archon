### 系统介绍
深度学习模型分享平台是一个面向人工智能领域的云端服务系统，旨在解决初学者和从业者在模型选择、训练、测试及部署过程中面临的困难与耗时问题。该应用程序不仅提供了一个专业、全面且易用的模型库，允许用户上传、下载和管理各种深度学习模型及数据集，还集成了知识共享功能，通过问答社区和博客板块促进用户间的技术交流。其核心旨在为用户打造一个集资源共享、在线体验、协作开发及付费收益于一体的一站式服务平台，帮助用户快速构建人工智能应用并提升专业水平。



### 核心目标
本系统旨在实现以下具体目标：

+ **构建知识共享社区**：建立问答社区和博客分享模块，方便用户提出问题、分享理论与实践案例，促进深度学习领域的知识交流。
+ **提供模型全生命周期管理**：实现对深度学习模型和数据集的上传、下载、修改与删除，方便用户管理资源。
+ **实现模型在线体验**：提供在线调用功能，使用户能直接测试模型效果（如图片分类），降低模型选取的门槛。
+ **建立商业变现机制**：允许用户对自己测试好的模型进行定价和售卖，为开发者提供经济收益渠道。
+ **优化资源推荐**：通过智能推荐算法，根据用户历史和偏好推荐感兴趣的模型内容。



### 功能特性
#### 1. 账号与个人管理
+ 当 **未登录用户填写合法的注册信息并提交** 时，**系统** 进行验证并创建新的普通用户账号。
+ 当 **用户忘记密码** 时，**用户** 通过注册邮箱进行验证并重设新密码。
+ 当 **用户登录后** 时，**用户** 可以修改个人信息或关注其他感兴趣的用户。

#### 2. 问答与博客社区
+ 当 **用户有疑问或想要分享知识** 时，**用户** 可以在社区发布问题或撰写博客文章。
+ 当 **用户浏览他人的问题或博客** 时，**用户** 可以发布回答或对博客文章进行评论。
+ 当 **用户对自己发布的内容不满意** 时，**用户** 可以修改或删除自己的问题、回答、博客文章及评论。

#### 3. 模型与数据集管理
+ 当 **用户开发了新模型** 时，**用户** 上传模型文件、编辑使用方法，并设置是否付费售卖。
+ 当 **用户需要获取资源** 时，**用户** 下载免费的数据集/模型，或支付购买付费模型后进行下载。
+ 当 **用户希望测试模型效果** 时，**用户** 在线调用已购或自有模型，运行特定任务（如使用数据集进行跑测）。
+ 当 **用户浏览模型板块** 时，**系统** 根据算法自动展示推荐的模型池。

#### 4. 管理员权限
+ 当 **平台出现违规账号** 时，**管理员** 执行注销用户账号的操作。
+ 当 **平台出现非法内容（问题、回答、博客、模型、数据集等）** 时，**管理员** 确认并删除相应的非法信息。



### 技术限制
+ **前端技术**：
    - Vue.js (JavaScript框架)。
    - TypeScript。
+ **后端框架**：
    - SpringBoot (基于Java)。
+ **数据库**：
    - MySQL。
+ **运行环境（客户端）**：
    - 所有现代浏览器，不支持 Internet Explorer。
+ **硬件环境（服务器）**：
    - CPU: x86-64 或 ARM 架构。
    - 内存: 不少于 4GB。
    - 硬盘: 不少于 30GB 可用空间。



### 非功能性需求
+ **处理时效与数据负载**
    - **并发能力**：系统应支持每秒 1000 次的应用请求。
    - **用户容量**：系统应能满足容纳 10,000 名以上用户的各类数据存储需求。
+ **安全性**
    - **防护机制**：系统需具备防止注入攻击等常见恶意操作的安全机制。
    - **权限控制**：必须对用户进行安全认证，并赋予管理员对违规用户进行功能限制（如注销、删除信息）的权限。
+ **可用性与鲁棒性**
    - **一致性**：保证在 3 秒的时间区间内，服务器数据和前端数据显示保持一致。
    - **稳定性**：在软硬件环境不变的情况下，期望失效时间应大于 1 年。
    - **故障恢复**：当系统因负载过高崩溃时，应在 1 小时内完成修复工作。
+ **灵活性与可维护性**
    - **自排错**：系统在无人工干预条件下应具有一定的自排错能力。
    - **可扩展性**：采用面向对象开发，通过模块化代码提供可扩充接口，确保业务需求可快速扩展。
+ **可移植性与多语言**
    - **语言支持**：界面需支持中文与英文之间的自由转换。

# 系统架构描述

### 1. 应用层 (Application Layer)

该层处于架构的最顶端，直接面向用户需求和特定的业务场景。它主要负责处理深度学习模型的全生命周期管理，包括模型的上传、发布、搜索、下载以及复杂的模型推荐逻辑。此外，该层还承载了社区社交交互（如博客评论、用户关注）及管理员的合规性审查逻辑。应用层关注的是业务流的完整性和用户体验的友好性，通过调用下层提供的通用能力，将抽象的用户意图转化为具体的业务操作指令。
### 2. 支撑层 (Support Layer)
支撑层为上层应用提供了一系列服务，包括统一的安全认证与权限控制机制（防止恶意操作与注入攻击）、数据一致性保障协议（确保前后端数据同步）、以及通用的日志记录与审计服务。该层屏蔽了底层复杂的数据存取和通信细节，通过定义良好的服务接口，支撑应用层在高并发和复杂推荐算法下的稳定运行。

### 3. 基础层 (Infrastructure Layer)

基础层涵盖了支撑深度学习大文件存储的分布式文件系统、处理高频读写需求的数据库引擎，以及保障各节点间高效通信的网络协议栈。该层不感知任何业务细节（如模型内容或用户身份），其核心职责是确保计算资源的可靠分发、数据的持久化安全以及系统的可扩展性，为上层所有组件提供透明且稳健的底层支撑。
