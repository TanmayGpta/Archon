# 系统介绍
智能文本标注与挖掘系统（ITAS）是一个旨在协助研究人员从海量PDF文献中高效、精准地标注段落和实体，并实现关键信息自动化提取与挖掘的综合性应用平台 。该系统主要服务于系统标注管理员、数据标注员以及科研人员，旨在解决传统手工标注过程耗时费力且易出错，以及现有第三方工具（如Diigo或阿里云NLP平台）在学术文献定制化标注、PDF直接处理、大批量抽取能力及标注质量控制等方面的局限性 。通过引入先进的大语言模型技术和多领域模块化设计，ITAS为学术研究及专业领域提供了强大的知识定位与利用工具，显著加速了科学发现和创新的过程 。

# 核心目标
+ **实现多领域标注支持**：通过模块化和可配置的预设，支持包括社会科学、生物医学、工程技术在内的广泛学科领域的特定标注需求 。
+ **提升人工标注效率与一致性**：提供用户友好的界面、预定义规则模板及智能推荐功能，降低标注难度并确保数据质量 。
+ **实现信息自动化提取**：利用大语言模型（如GPT系列）和自然语言处理技术，实现从文档中自动化提取预设的关键信息，支持小样本学习以应对数据稀缺场景 。
+ **构建社区协作生态**：建立共享机制，允许用户分享标注预设、模型和语料库，促进跨学科的知识共享与社区协作 
+ **保障标注数据质量**：通过精准定位、数据校验和质量控制功能，为科研和模型训练提供可靠的标准化数据集。

# 功能特性
**文本标注子系统**

+ **项目创建**：当标注管理员需要启动新任务时，管理员进行填写项目信息、上传待标注文档、定义标签Key及分配标注人员等动作 。
+ **账号注册**：当用户首次访问系统时，数据标注员进行输入账户密码、系统验证合法性及密码强度等动作 。
+ **系统登录**：当已注册用户访问系统时，数据标注员进行输入凭证、系统校验账号存在性及密码正确性等动作 。
+ **执行标注**：当任务分配完成且状态为未完成时，数据标注员进行加载文档、根据系统指引对段落和关键信息进行标记等动作 。
+ **项目验收**：当标注人员提交任务后，标注管理员进行审核标注结果、导出标准化数据（JSON/XML）或重新分配任务等动作 。



**智能挖掘子系统**

+ **文档处理**：当科研人员上传PDF文献时，系统进行格式验证、将其转换为TXT格式并完成前端可视化渲染等动作 
+ **模型选择**：当准备进行数据挖掘时，科研人员进行从系统预设、社区共享或第三方接口（如ChatGPT）中选择模型并设置微调参数等动作 。
+ **自动化提取**：当文档转换和模型选择完成后，系统进行自动定位包含关键信息的段落并识别文本中特定实体等动作 。
+ **模型共享**：当科研人员完成模型微调后，科研人员进行填写模型描述并将其上传至社区预设库以供他人使用等动作 。
+ **标注反馈**：当查看自动化提取结果后，科研人员进行对识别结果进行编辑、修正并提交反馈以供模型迭代优化等动作 。

# 技术限制
+ **后端框架**：使用 Spring Cloud（微服务架构架构）或 Flask Web框架 。
+ **数据库**：
    - **关系型数据库**：MySQL 8.0 。
    - **图数据库**：Neo4j 。
    - **缓存技术**：Redis 6.0 。
    - **文件存储**：Minio 。
+ **编程语言**：Python（后端）、TypeScript（前端代码风格规范涉及）。

# 非功能性需求
+ **处理时效**：
    - 打开标注文档的时间应控制在5秒以内 。
    - 标注操作响应时间应在0.5秒以内 。
    - 单个文档转换处理时间应在5至10秒之间 。
    - 单次信息提取的响应时间不超过60秒 。
+ **安全性**：
    - **访问控制**：实现基于角色（RBAC）的权限管理机制，严格限制各类用户对数据和功能的访问 。
    - **数据保护**：采用AES-256算法对敏感数据加密存储，传输过程强制使用HTTPS协议 。
    - **审计监控**：详细记录所有用户的操作日志，以便追溯安全风险并监控用户行为 。
+ **可用性**：
    - **故障处理**：系统需具备完善的错误检测、报告及自动恢复机制（如重连、重试）。
    - **容错能力**：对于不可恢复错误，需提供数据备份和故障转移机制，确保用户数据的安全性和系统连续性 
+ **灵活性**：
    - **解耦设计**：采用低耦合、高内聚原则，通过接口定义和消息传递实现模块间通信，便于功能调整或重构。
    - **扩展能力**：支持组件扩展和功能升级，允许通过插件化开发添加新功能，并保持向后兼容性 。
+ **可移植性**：
    - **跨浏览器支持**：要求支持主流现代浏览器（Chrome、Edge、Firefox、Safari等）的最新稳定版 。
    - **环境兼容**：系统需能在Ubuntu、CentOS等不同Linux发行版上稳定运行 。


# 系统架构描述

### 1. 应用层 (Application Layer)

应用层将支撑层提供的原子能力整合为具有业务意义的功能逻辑，如多领域文献标注流程、智能挖掘项目管理及社区化预设共享。该层通过高度解耦的微服务架构处理用户交互逻辑，并利用支撑层的 AI 预测能力实现从 PDF 到结构化知识的转化，其设计独立于底层技术栈的变化，确保了系统能够灵活迁移至不同的学术或研究领域。
### 2. 支撑层 (Support Layer)

深度集成了自然语言处理库与深度学习框架（如 PyTorch、TensorFlow），将复杂的人工智能算法封装为标准化的能力组件，如语义理解、实体识别和格式解析服务。同时，该层还承担了横切关注点的职责，通过统一的 RESTful API 协议实现前后端的数据路由，并内置了基于角色的访问控制（RBAC）、操作日志审计及安全加密机制，确保了业务逻辑在安全可控的环境中运行。

### 3. 基础层 (Infrastructure Layer)

涵盖了高性能计算资源（如多核、高主频 CPU 及大容量内存）和高速存储网络，还集成了多样化的数据持久化机制，包括用于结构化数据的关系型数据库、用于非结构化文档的对象存储，以及用于高性能检索的缓存系统。其核心职责是为上层屏蔽底层硬件与操作系统的物理差异，提供稳定、可扩展的分布式运行环境。
