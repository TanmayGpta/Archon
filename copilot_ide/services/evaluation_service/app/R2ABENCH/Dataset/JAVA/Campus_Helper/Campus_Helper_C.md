# 系统介绍
北航校园帮帮平台是一款基于**微信小程序**框架开发的校园生活服务交易平台。该程序采用展示层、业务层、数据层及数据库的**四层架构**设计，旨在解决北航师生在沙河及本部校区因封闭管理带来的快递/外卖代取困难，以及校内二手交易信息杂乱、缺乏检索功能等核心痛点。系统通过“发布-接单”模式提供跑腿服务，并构建规范的二手交易信息发布环境，为北航学生、教师及家属提供便捷的生活支持。

# 核心目标
+ **构建代取服务体系**：通过“发布-接单”机制，为校内用户提供外卖及快递的代取跑腿服务。
+ **实现外卖即时转让**：帮助无法及时领取外卖的用户通过平台进行即时交易，减少资源浪费。
+ **规范二手交易环境**：提供分类明确、支持检索的二手信息发布地，替代杂乱的群聊交易模式。
+ **优化信息检索效率**：通过热门排序、分类搜索、标签匹配及时间过滤等多维度功能，提升用户获取有效信息的效率。
+ **保障平台运营安全**：设立管理员职能，负责监督违规商品、管理用户信息及维护交易秩序。

# 功能特性
**商品查看与搜索**

+ 当用户或游客进入主界面时，展示层按热门程度规则对商品进行排序显示。
+ 当用户选择特定分类、标签或时间段时，系统筛选并按时间降序排列展示相关商品列表。
+ 当用户点击某一商品条目时，系统跳转至详情页面展示商品位置、金额及详细描述。

**订单交易流程**

+ 当已登录用户选择商品并填写收货信息提交时，系统验证有效性并在数据库插入订单记录。
+ 当订单尚未被承接或送出时，用户可以修改订单备注或取消该二手订单。
+ 当用户收到商品后，在订单详情页面点击确认，系统更新订单状态为“已完成”。

**个人中心与收藏**

+ 当用户点击商品收藏按钮时，系统将该条目添加至用户的收藏列表以便后续查看。
+ 当用户进入个人中心并点击相关按钮时，系统展示该用户的所有收藏商品或历史订单记录。

**后台管理**

+ 当管理员登录后台时，系统直接展示平台商品总数、代取请求数及二手商品数等总体情况。
+ 当管理员发现违规内容时，可以对特定商品进行信息修改或执行二次确认后的删除操作。
+ 当需要维护秩序时，管理员可检索并修改用户余额、发货地址等用户信息，或调整订单详情。

# 技术限制
+ **移动端平台**：支持 **Android 5.0** 及以上操作系统的移动设备。
+ **后端框架**：采用**展示层/业务层/数据层**的四层架构，且需遵循 Web 编码规范。
+ **数据库**：包含**数据实体层**，需支持 **GB 级数据**存储，单表行数建议不超过 10 万行。
+ **编程语言**：基于**微信小程序开发框架**，支持 **微信 8.0** 及以上版本。

# 非功能性需求
+ **处理时效**：一般时段响应时间需在 **1.5 秒内**，高峰期不超过 4 秒；特定搜索需在 3 秒内得到结果。
+ **安全性**：要求识别恶意行为率 > 98%，具备 **SQL 注入防护**及输入参数验证；实施基于角色的访问控制。
+ **可用性**：系统需具备高可靠性，能识别非法输入并在意外故障时保证其他模块正常运行；支持故障后的**服务回滚、重启或紧急更新**。
+ **灵活性**：功能模块需进行**解耦设计**，文档书写规范，以保证良好的可维护性。
+ **可移植性**：运行于微信小程序环境，需兼容微信 8.0+ 及多种移动硬件配置。

# 系统架构描述

### 1. 应用层 (Application Layer)

该层位于架构的最顶端，其主要职责是处理“北航帮帮”的核心业务逻辑，包括跑腿商品（外卖、快递代取）与二手物品的生命周期管理、订单状态流转（创建、确认、取消）以及个人中心的数据呈现。应用层通过接收来自移动端的交互指令，将抽象的校园服务需求转化为结构化的业务流，并负责处理各类参与者（卖家、顾客、管理员）在特定上下文下的身份切换与权限校验。
### 2. 支撑层 (Support Layer)
支撑层向下封装了复杂的数据存取操作，向上为业务逻辑提供统一的调用接口。其核心职责包括：实现基于标签和模糊匹配的搜索引擎、处理高并发下的请求队列、维护系统安全性的过滤机制（如防SQL注入、参数验证）、以及执行自动化运维支撑（如故障处理监控、日志审计等）。它作为“中间人”，确保了业务逻辑与数据存储之间的松耦合，使得上层应用无需关心数据的物理存储细节。

### 3. 基础层 (Infrastructure Layer)

基础层基于微信小程序运行环境和安卓底层系统，构建起端到端的 HTTPS 通信平面。该层不仅负责底层硬件资源的分配（如 CPU、内存、存储），还通过数据库管理系统提供可靠的数据持久化与分发机制。其主要目标是为上层提供透明的计算能力和稳定的吞吐保障，通过集群与服务器运行环境确保系统的响应时延与负载均衡。
