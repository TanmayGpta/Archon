# 系统介绍

本项目是一款集专业姿态评估、科学运动激励与趣味分享于一体的智能化室内健身应用程序。该软件利用计算机视觉中的姿态估计技术，将移动设备摄像头转化为“虚拟私人教练”，旨在为业余运动爱好者（如学生、上班族）及专业健身教练解决因快节奏生活导致的健身时间受限和场地选择难题。系统通过在居家、办公室等多种碎片化场景下提供实时的动作纠偏、身体状态监测及个性化运动报告，确保用户即便在没有专业教练在场的情况下，也能获得科学、标准且具有趣味性的健身指导体验。

# 核心目标

* 实现高精度的实时人体姿态监测与骨架提取，提供动作标准度评分。
* 根据用户体质、限制条件和实时运动反馈，动态制定并调整科学的训练计划。
* 通过可视化数据图表生成专业运动报告和训练海报，增强运动的激励性与社交分享欲。
* 支持多设备协同，通过运动投屏功能优化用户在锻炼过程中的视觉观察体验。
* 提供全天候（24小时）且不限空间的健身指导服务，满足碎片化健身需求。
* 确保软件具备高度的易用性，最终用户调查满意度达到90%以上。

# 功能特性

### 专业评估功能模块

* 当用户开始拍摄运动视频时，终端设备实时提取骨架信息并与标准动作进行比对评分。
* 当运动进行中时，系统实时监测运动状态数据并结合体质标准评估实际完成情况。
* 当用户在手机端查看实时画面时，系统以姿势棒图形式展示评估结果并显示动作剩余时间。

### 智能推荐功能模块

* 当用户初次使用或更新状态时，系统综合用户目标、身体状况及限制条件制定系统训练计划。
* 当用户处于运动小组实时训练中时，系统根据其实时疲劳或完成情况，自动调整并推送下一组运动或休息计划。
* 当用户完成专业评估模块后，系统在运动结束界面提供针对性的进阶计划推荐。

### 趣味分享功能模块

* 当用户完成至少一次训练后，系统根据姿态数据、图片及计划信息生成可供保存分享的训练海报。
* 当训练结束需要总结时，系统使用可视化方法生成包含专业统计数据和文字解释的运动报告。

### 运动投屏功能模块

* 当用户在局域网环境下点击投屏功能时，系统自动搜索并连接同一局域网下的安卓大屏设备。
* 当投屏连接成功后，系统将手机侧的实时运动画面、评估结果镜像投送到目标设备。

# 技术限制

1. **移动端平台**：支持安卓 8.0 或 iOS 11.0 及以上版本。
2. **编程语言**：使用python语言进行后端开发。
3. **硬件约束**：
    * **移动端**：需满足八核 2.45GHz CPU，4GB RAM + 32GB ROM 及以上配置。
    * **服务器**：需满足 Pentium 900M（推荐 P4 1.2G）处理器，256M 以上内存。
    * **采集端**：用户的手机必须支持 30fps 及以上的视频录制。

# 非功能需求

* **处理时效 (Performance)**：姿态估计模型需达到 20fps 以上的运行速度；计划推荐生成时间需在 1s 内；运动报告生成需在 3s 内；投屏视频流延迟需控制在 100ms 以内，指令响应延迟在 50ms 以内。
* **安全性 (Security)**：需具备泄密保护技术（防止内存窃取、截屏等）；实施严格的用户身份验证与权限管理（区分管理员与普通用户）；具备防止 SQL 注入的预编译与过滤机制。
* **可用性 (Availability)**：在正常光照与无遮挡环境下，姿态识别准确率需达到 95% 以上；即使在遮挡场景下，未遮挡部位的识别准确率也需保持在 90% 以上。
* **灵活性 (Flexibility/Scalability)**：采用模块化设计思想，各模块间通过接口进行数据交换，以便于后续的功能扩展与逻辑维护。
* **可移植性 (Portability)**：基于模块化设计，支持功能模块在不同系统环境下的迁移与集成。

# 系统架构描述

### 1. 基础层 (Infrastructure Layer)

该层作为系统的底层支撑，主要负责基础硬件资源的调度与核心算法的算力分发。它封装了移动端摄像头采集、跨设备局域网通信以及大规模数据存储（静态标准库与动态用户库）等物理细节。在计算能力上，它提供了人体关键点检测与骨架提取的底层视觉引擎，将原始视频流转化为可供计算的结构化向量数据，为上层应用屏蔽了复杂的底层感知和网络传输协议。

### 2. 支撑层 (Support Layer)

该层通过一系列高度内聚的服务模块，将基础层的原始数据转化为具有运动语义的业务支撑。其核心职责包括：

* **评估与计算服务**：执行姿态相似度比对，利用算法消除用户体型差异，将骨架向量转化为标准化的运动评分。
* **分析与生成服务**：对运动日志进行聚合，支持数据可视化渲染与多媒体海报的异步生成。
* **通信中间件**：管理镜像投屏的流媒体同步与指令响应，确保低延迟的数据交换。
该层通过接口化的方式，为应用层提供了一套稳定的运动分析原语。

### 3. 应用层 (Application Layer)

该层聚焦于特定业务场景的逻辑编排，是系统与用户交互的最终表现。它根据用户的运动目标与实时身体状况，驱动**智能推荐逻辑**进行训练计划的动态调整，并负责管理**运动监测、报告展示、社交分享**等具体业务流。应用层无需关注姿态估计是如何通过视觉算法实现的，只需调用支撑层的评估结果来完成“动作指导”与“进度反馈”的业务闭环，从而实现了业务逻辑与底层技术的完全解耦。
