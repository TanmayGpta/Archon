# 系统介绍

PromptHub 是一款专注于 AI 画作及其提示词（Prompt）分享的社区类 Web 应用程序。在 AI 绘画技术日益普及的背景下，该平台旨在为广大 AI 绘画创作者、爱好者及新手提供一个高效、便捷的 Prompt 分享与探索空间。其核心价值在于通过分享不同模型和提示词创作的艺术作品，帮助用户在创作时选择更精确的指令，从而绘制出更符合需求的作品。系统旨在解决用户在寻找优质 AIGC 内容、学习 Prompt 技巧以及进行社区互动时的核心痛点，构建一个富有想象力的 AI 艺术交流社区。

# 核心目标

* **资源共享**：提供一个平台供创作者分享 AI 作品、相关模型信息及精确的 Prompt。
* **高效检索**：支持用户通过提示词、类别或多级检索功能快速定位符合偏好的作品。
* **社区互动**：建立评论与点赞系统，促进用户间关于 AI 绘画技术的交流与提问。
* **内容质量管控**：通过管理员审核机制，过滤低劣作品，维护社区内容质量。
* **个性化服务**：基于用户行为（收藏、关注等）提供个性化推荐及作品管理功能。

# 功能特性

### 用户/游客系统

* **注册触发**：当游客在首页点击注册并输入信息时，系统进行邮箱验证并创建新账号。
* **登录触发**：当用户输入正确的账号名和密码时，系统进行身份验证并允许其访问受限功能。
* **信息修改**：当用户进入个人设置时，用户进行头像、用户名修改或密码重置动作。
* **社交互动**：当用户浏览他人主页时，用户进行关注或取消关注该用户的操作。

### 展示与管理系统

* **作品上传**：当用户提交 AI 画作及其 Prompt 时，展示系统进行上传记录并等待审核。
* **作品审核**：当管理员查看待审核列表时，管理员进行通过或拒绝作品的判定动作。
* **检索查询**：当用户输入关键词或选择排序方式时，展示系统进行作品筛选与陈列展示。

### 收藏与评论系统

* **收藏管理**：当用户点击收藏按钮时，收藏系统进行作品分类存储（Public/Private）动作。
* **评论互动**：当用户在作品详情页输入内容时，评论系统进行评论发表或对他人的回复动作。
* **违规清理**：当管理员发现不良言论时，管理员进行删除评论或回复的动作。

### 推荐与通知系统

* **消息推送**：当作品审核进度变更或收到互动时，通知系统进行实时消息推送动作。
* **智能推荐**：当用户开启个性化服务时，推荐系统根据用户偏好进行相似作品推荐。

# 技术限制

1. **移动端平台**：**基于 Windows 7、macOS 8.0 及以上版本**内核的图形界面操作系统环境。
2. **后端框架**：使用 **Django** 框架。
3. **数据库**：初级开发阶段使用 **SQLite**（轻型数据库引擎），后续迭代计划迁移至 **MySQL**。
4. **编程语言**：
* 前端：HTML, CSS, **JavaScript**。
* 后端：**Python**, **Java**。
* 算法支持：**Python**。

# 非功能性需求

* **处理时效 (Response Time)**：系统应具备良好的响应能力，在普通带宽下，页面加载和功能跳转应在用户可接受的范围内，避免长时间卡顿。
* **安全性 (Security)**：通过密码加密存储、强制身份验证（如邮箱验证码）来控制访问；系统需具备限制同一时刻访问量的能力以保证稳定运行。
* **可用性 (Availability)**：系统需保证操作的原子性（如数据库更新），并具备一定的健壮性，在网络连接正常的依赖下，确保核心业务流程不中断。
* **灵活性 (Flexibility/Scalability)**：代码结构需清晰且模块化（如分层架构），以便于后续功能的迭代和数据库的迁移（如从 SQLite 迁移至 MySQL）。
* **可移植性 (Portability)**：系统需支持跨浏览器运行，兼容 Firefox (内核119.0+) 及 Chromium (内核110.0+) 等主流浏览器内核。

# 系统架构描述

### 1. 应用层 (Application Layer)

该层面向最终用户（游客、普通用户、管理员），关注具体的业务场景与产品原生细节。其核心职责是实现**业务逻辑的闭环**，通过“用户系统”、“展示系统”、“收藏系统”、“评论系统”以及“管理员审核系统”等模块，处理用户与 AI 画作/Prompt 之间的交互。它独立于硬件，直接响应业务需求（如作品上传、Prompt 分类检索、个性化推荐开关等），并将业务意图转化为对下层服务的调用。

### 2. 支撑层 (Support Layer)

此层提供**职责内聚的通用服务集合**。它通过封装通用逻辑起到了桥接高层应用与底层基础设施的作用。

* **服务内聚性**：包含“推荐系统”（处理复杂的排序与偏好算法逻辑）和“通知系统”（处理异步消息推送）。
* **开发框架支撑**：利用 **Django** (Python) 和 **Vue.js** 框架提供的 MTV/组件化编程模型，为应用层提供结构化的逻辑支撑与界面渲染能力。
* **计算支撑**：通过 **PyTorch** 和 **Tensorflow** 框架为上层的 AI 作品生成与分析提供算法支持。

### 3. 基础层 (Infrastructure Layer)

该层是系统的物理与逻辑底座，与具体的 AIGC 业务无关，专注于底层计算、存储与分发机制。

* **存储机制**：采用轻量化的 **SQLite** 数据库引擎，负责数据的物理持久化。
* **交付与运行环境**：利用 **Docker** 容器化技术构建可移植的运行环境，确保系统能在不同操作系统（如 Windows, macOS）及浏览器内核（Chromium, Firefox）上稳定运行。
* **通信基础**：完全依赖基础网络连接，作为所有功能实现的先决条件。
